# Welcome to Velse Platform

Velse is a comprehensive learning journal, DevSecOps portfolio, and security project tracker. This space compiles research notes, detailed guides, and security configurations.

## Explore Categories

Select a category below or use the sidebar directory tree to navigate through the files:

*   ### [🛡️ Cloud Security Guides](./Cloud_Security_Guides/Cloud_Security_Guides_merged.md)
    Deep dive into AWS cloud security checklists, CNAPP (Cloud Native Application Protection Platform) policy configurations, financial compliance frameworks, and unified mastery playbooks.
    
*   ### [☸️ Container & Kubernetes Security](./Container_K8s_Security/Container_K8s_Security_merged.md)
    Hands-on guides covering container scanning, Kubernetes runtime detection policies, vulnerability scanning automation, and secure CI/CD orchestration.
    
*   ### [📊 Data Analytics](./Data_Analytics/Data_Analytics_merged.md)
    Analytical guides, visualization models, and performance logs related to cloud security data and audit analytics.
    
*   ### [💼 Interview Prep](./Interview_Prep/Interview_Prep_merged.md)
    Consolidated question banks, cheat sheets, and architecture challenges for DevSecOps, cloud infrastructure, and security engineering roles.

## 🛠️ Platform Features

- **Markdown & PDF Support**: Click on any document or guide in the sidebar to read it instantly. PDF reference guides are rendered natively in the browser.
- **GitHub Integration**: Authenticate through the settings panel to enable interactive editing, renaming, deleting, and uploading posts directly synced back to your repository.
- **Export to PDF**: Generate clean PDF layouts of any Markdown guide at the click of a button.
